# Página de Muñecos XO

Bienvenido a la página web de **Muñecos XO**. Este proyecto es una plataforma interactiva y responsiva para la visualización y catálogo de personajes únicos con diseño moderno y animaciones fluidas.

## 📋 Descripción del Proyecto

Una página web dedicada a mostrar una colección de muñecos con temática XO, con un sistema de catálogo interactivo, animaciones dinámicas y diseño responsive que se adapta a todos los dispositivos.

## 🎨 Características

- ✨ **Animaciones Dinámicas**: Utilizando GSAP para efectos visuales suaves y profesionales
- 📱 **Diseño Responsive**: Compatible con dispositivos móviles, tablets y desktop
- 🎯 **Catálogo Interactivo**: Sistema de visualización de productos elegante
- 🎭 **Personajes Únicos**: Múltiples muñecos con diseños especiales
- 🎨 **Tipografías Personalizadas**: Fuentes premium (Lobster, Pacifico, Indie Flower, Playfair Display)
- 🚀 **Interfaz Moderna**: Basado en Bootstrap 5.3.7

## 🚀 Cómo Empezar

### Requisitos Previos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Servidor web local o servidor XAMPP (recomendado)

### Instalación

1. Coloca el proyecto en la carpeta `htdocs` de XAMPP:
   ```bash
   c:\xampp\htdocs\pagina-munecos-xo
   ```

2. Inicia XAMPP y activa Apache

3. Abre tu navegador y accede a:
   ```
   http://localhost/pagina-munecos-xo/
   ```

## 📖 Páginas Principales

### Página de Inicio (`index.html`)
Página principal con presentación de la marca y navegación hacia el catálogo.

### Catálogo (`html/catalogo–primary.html`)
Visualización interactiva de todos los muñecos disponibles con detalles y opciones de visualización.

## 🎬 Animaciones

Las animaciones del proyecto utilizan la librería **GSAP** para garantizar:
- Transiciones suaves y fluidas
- Rendimiento optimizado
- Compatibilidad con navegadores modernos

Las animaciones se encuentran principalmente en `JS/animation.js`.

## 📸 Recursos Visuales

Todas las imágenes están organizadas en la carpeta `assent/img/`:
- **Fondos**: Fondos de página
- **Iconos**: Iconos temáticos XO
- **Logos**: Branding y logos del creador
- **Muñecos**: Imágenes de los personajes en diferentes tamaños
- **Trabajos**: Portfolio y trabajos relacionados

## 🎨 Tipografías

El proyecto utiliza las siguientes fuentes personalizadas:
- **Lobster**: Titulares y texto destacado
- **Pacifico**: Textos decorativos
- **Indie Flower**: Textos casuales y amigables
- **Playfair Display**: Títulos elegantes

## 💻 Desarrollo

### Estructura de Archivos CSS
- `styleinicio.css`: Estilos específicos de la página de inicio
- `stylecatalogo2.css`: Estilos específicos del catálogo
- `responsive.css`: Media queries y ajustes responsive

### Estructura de JavaScript
- `animation.js`: Todas las animaciones y efectos interactivos

## 🔧 Personalización

Para personalizar el proyecto:

1. **Colores y Estilos**: Edita los archivos CSS en `css/`
2. **Contenido**: Modifica los archivos HTML
3. **Animaciones**: Ajusta `JS/animation.js` utilizando GSAP
4. **Imágenes**: Reemplaza o agrega nuevas imágenes en `assent/img/`
5. **Fuentes**: Añade nuevas fuentes en `assent/fonts/`

## 📝 Notas Importantes

- Asegúrate de mantener la estructura de carpetas intacta para que las rutas de recursos funcionen correctamente
- Las rutas de imágenes y recursos son relativas, por lo que es importante no mover archivos sin actualizar las referencias
- Verifica que XAMPP esté ejecutándose para servir la página correctamente
